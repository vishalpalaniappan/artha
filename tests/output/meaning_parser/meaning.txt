=================
coffee shop
=================
      initialize Cart
      present menu --> COMPOSITE MEANING


=================
present menu
=================
      Barista presents the menu to the user --> COMPOSITE MEANING
    then
      accept the menu choice from the user --> COMPOSITE MEANING
    if
      the user selected Coffee --> COMPOSITE MEANING
    then
      add Coffee to Cart --> COMPOSITE MEANING
    then
      present menu --> COMPOSITE MEANING
    if
      the user selected Bagel --> COMPOSITE MEANING
    then
      add Bagel to Cart --> COMPOSITE MEANING
    then
      present menu --> COMPOSITE MEANING
    if
      the user cleared the transaction --> COMPOSITE MEANING
    then
      clear the Cart --> COMPOSITE MEANING
    then
      present menu --> COMPOSITE MEANING
    if
      the user proceeded with the payment --> COMPOSITE MEANING
    then
      process payment --> COMPOSITE MEANING
    then
      present menu --> COMPOSITE MEANING
    if
      the user decided to leave the store --> COMPOSITE MEANING
    then
      close the store --> COMPOSITE MEANING


=================
accept the menu choice from the user
=================
      accept terminal input and store in user_input --> PRIMITIVE MEANING: terminal_input
      # TODO : Add errors after extending primitive syntax
      # EOF is reached without data : present menu
      # keyboard interrupt is triggered : close store


=================
close the store
=================
      display goodbye_message in terminal --> PRIMITIVE MEANING: display_terminal


=================
Barista presents the menu to the user
=================
      get formatted menu and store in formatted_menu
      display formatted_menu in terminal --> PRIMITIVE MEANING: display_terminal


=================
the user selected Coffee
=================
      menu_choice equals "coffee" --> PRIMITIVE MEANING: equal


=================
the user selected Bagel
=================
    resolve
      menu_choice equals "bagel" --> PRIMITIVE MEANING: equal


=================
the user cleared the transaction
=================
    resolve
      menu_choice equals "clear" --> PRIMITIVE MEANING: equal


=================
the user proceeded with the payment
=================
    resolve
      menu_choice equals "checkout" --> PRIMITIVE MEANING: equal


=================
the user decided to leave the store
=================
    resolve
      menu_choice equals "leave" --> PRIMITIVE MEANING: equal


=================
process payment
=================
      calculate cost --> COMPOSITE MEANING
    then
      hand user the bill --> COMPOSITE MEANING
    then
      accept payment from user --> COMPOSITE MEANING


=================
total_cost
=================
      it has structural type float --> PRIMITIVE MEANING: it_has
      it has role type accumulated_cost --> PRIMITIVE MEANING: it_has


=================
initialize cost
=================
      set total_cost to zero


=================
calculate cost
=================
      add total_cost to world
      initialize cost --> COMPOSITE MEANING
    for
      each item in cart add cost of [item] to total_cost


=================
add cost of [item] to [total_cost]
=================
      get cost of [item] and store in item_cost
      add item_cost and [total_cost] and store result in [total_cost] --> PRIMITIVE MEANING: add


=================
hand user the bill
=================
      set user_prompt to "User owes [total_cost]" with type string
      prompt terminal with user_prompt


=================
accept payment from user
=================
      # TODO : Verify payment amount
      accept user_payment from terminal

      it has structural type Object --> PRIMITIVE MEANING: it_has

      it has an attribute named cost which is a float and has a value of 2 00
      it has an attribute named cost_currency which is a string and has a value of "CAD"

=================

      insert Coffee at end of Cart


=================
add Bagel to Cart
=================
      # Cart only contains food item so there is an invariant that the item being inserted has to be of type food item
