Using Artha (which means meaning), software systems can be constructed by specifying their meaning and the narratives that reason about that meaning, resulting in deterministic intelligence. An engine reasons about the meaning of the automatically constructed world to eliminate failures and a deterministic learning process enabled by domain specific compression expands the meaning of the world so the software system can successfully realize its intentions in reality.

This repo will be populated as each component in the framework is established.

Prior to reaching this stage, the following will be constructed:
- Computable Semantic Primitives (CSP)
- Computable Semantic Models (CSM)

This will enable:
- Using the CSM's, a toolkit of meaning will be established.
- Meaningful narratives about the world can be constructed from the meaning.
- The world will be automatically constructed from the meaning.
- An engine can reason about the meaning to determine if it is internally consistent and eliminate all known failures.

As a result the implementation of the software system is automatically synthesized from its meaning, ultimately automating the development of software systems.
