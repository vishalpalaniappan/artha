Using Artha (which means meaning), software systems can be constructed by specifying their meaning and the narratives that reason about that meaning, resulting in deterministic intelligence. The closed semantic world that is described by the established meaning is automatically constructed, an engine reasons about the meaning to eliminate failures and a deterministic learning process supported by domain specific compression expands the meaning of the world so the software system can successfully realize its intentions in reality.

This repo will be populated as each component in the framework is established.

Prior to reaching this stage, the following will be constructed:
- Computable Semantic Primitives (CSP)
- Computable Semantic Models (CSM)
- An engine that can reason about the meaning of the CSM.

As a result:
- Using the CSM's, a toolkit of meaning will be established.
- Meaningful narratives about the world can be constructed from the meaning.
- The world will be automatically constructed from the meaning.
- An engine can reason about the meaning to determine if it is internally consistent and eliminate all known failures.

This means that the implementation of the software system is automatically synthesized from its meaning. Through reasoning about the meaning of the world, the known failures are eliminated and a deterministic learning loop expands the meaning of the world through root cause analysis when reality rejects the designs assumptions. Ultimately, this process automates the development and management of software systems.
