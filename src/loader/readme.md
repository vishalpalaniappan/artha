Loads the artha design file by reading the meta JSON file. It parses the main artha file and the imported files. It produces a package that is sent to the reasoning engine. This method will run in the workbench everytime the file is saved. When parsing, if there are syntax errors or missing config information (like a meta file), this will present the relevant information. Also, in the future, I can add a script to create a new artha project etc.
